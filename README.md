# 바둑 게임

초등학생(2~6학년)이 하면서 배우는 바둑 게임입니다. 아이패드에 맞춰 만들었습니다.

## 대국하기
- **🎯 따먹기**: 돌을 1·3·5개 먼저 잡으면 이깁니다 (처음 배울 때)
- **🏠 집 짓기**: 진짜 바둑, 계가 (덤 6.5집)
- 9 · 13 · 19줄 바둑판
- 컴퓨터 4단계: 🌱 새싹 → 🌿 새잎 → 🌳 나무 → ⛰️ 산
- 친구와 한 화면에서 대국
- 💡 힌트, 무르기, 한 수 쉼, 기권
- 🧑‍🏫 배움 도우미: 단수인 돌 표시, 숨구멍 미리보기, 쉬운 설명

## 배우기 (25문제)
**🌱 기초 · 2~3학년 (13)**: 숨구멍 알기, 돌 잡기, 내 돌 살리기, 양단수
**🌿 중급 · 4학년 (5)**: 잇기와 끊기, 몰아서 잡기, 수상전, 패
**🌳 고급 · 5~6학년 (7)**: 축, 환격, 사활(눈 두 개, 급소)

축·환격·수상전은 백이 자동으로 받아 두는 연속 문제입니다.
푼 문제는 ⭐로 표시되고 기기에 저장됩니다.

`index.html` 파일 하나로 동작합니다.
